# AXZ ReceiptCI v1.0.0

First public release of AXZ ReceiptCI, a deterministic CI receipt engine that verifies tests, hashes project files and artifacts, and emits reproducible JSON release certificates.

## Includes

- `axz-receiptci verify`
- `axz-receiptci check`
- source-tree SHA-256 manifest hashing
- JSON certificate output
- human-readable receipt output
- SHA256SUMS ledger
- GitHub Actions workflow
- tests across Python 3.10, 3.11, 3.12, and 3.13
