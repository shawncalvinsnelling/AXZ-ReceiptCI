# Commercial Open Source Path

Open-source core:

- local CLI receipt generator,
- GitHub Actions workflow,
- JSON certificate format,
- source and artifact hashing,
- receipt verification.

Future paid layer:

- hosted receipt dashboard,
- private artifact registry,
- audit logs,
- compliance exports,
- team policy management,
- enterprise SSO,
- AI-code verification logs.

The commercial thesis is simple:

```text
Developers get a free deterministic receipt engine.
Enterprises pay to manage, audit, search, and enforce receipts at scale.
```
