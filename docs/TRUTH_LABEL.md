# Truth Label

```text
CERTIFIED_BUILD_RECEIPT_ENGINE_V0
```

This project certifies finite CI/build verification runs by hashing inputs, running a declared verifier command, and emitting a machine-readable receipt.

It does not claim:

- universal software correctness,
- a replacement for formal verification,
- a replacement for SLSA/Sigstore/Nix/Bazel,
- that an AI patch is safe without testing,
- that a passing receipt proves bug-free software.
